ActPilot Privacy Policy

Effective & last updated: September 11, 2026  ·  Developed by QueryNest

In plain English
  • ActPilot reads the page you're on only when you ask it something — it doesn't watch your browsing.
  • What it reads (page text, a screenshot, form fields) is sent to our server to generate an answer, then discarded — we don't keep a copy of your pages or conversations.
  • No account, no sign-in, and no data is sold or shared with advertisers.
  • The only thing we retain is a request counter tied to your IP address, used to enforce the free-tier limit, which resets automatically every 2 hours.

What ActPilot accesses, and when

ActPilot is a browser extension that answers questions about the page you're viewing and, when you ask it to, fills in form fields, clicks page elements, or opens a search result for you. It only does any of this in direct response to a message you type into its side panel — there is no background monitoring of the sites you visit.

When you send a message, ActPilot reads, from the current tab only:

  • The page's URL, title, and visible text content
  • A screenshot of the currently visible portion of the tab
  • A list of the page's fillable and clickable elements (their type, label, and placeholder text) — used only when your request involves filling or clicking something

How that information is used

Your question, together with the page information above, is sent over the network to ActPilot's backend server, which forwards it to a third-party AI model — Azure OpenAI by default, or Groq as an automatic fallback — to generate the answer or the list of actions to perform on the page. The answer is returned to the extension and shown in the side panel; any requested actions (filling a field, clicking a button, opening a link) are then carried out directly in your browser.

Neither Azure OpenAI nor Groq is instructed to retain your data for training, and ActPilot's own backend does not write your page content, screenshots, or conversation history to a database or log file — each request is processed in memory and discarded once the response is sent.

What we store

The only server-side state ActPilot keeps is a per-IP-address message counter, used to enforce the free tier's 50-messages-per-2-hours limit. It resets automatically on a rolling basis and contains no page content, no conversation text, and no identifying information beyond the IP address itself.

If you use the “Download chat” feature, your conversation is formatted into a PDF on the server and streamed directly back to you — it is not saved anywhere afterward.

Permissions this extension requests

PermissionWhy it's needed
activeTab, host accessTo read the text and elements of the page you're currently asking about, and to fill/click on it when you request an action.

storageReserved for future use (e.g. remembering your preferences locally); ActPilot does not currently store personal data with it.

Your choices

  • ActPilot only acts when you send it a message — simply not using it on a given page means nothing is read from that page.
  • Uninstalling the extension immediately stops all access to page content.
  • Because there is no account system, there is no stored profile to delete — your only persistent footprint is the anonymous rate-limit counter described above, which expires on its own.

Children's privacy

ActPilot is not directed at children under 13 and does not knowingly collect information from them.

Changes to this policy

If this policy changes, the “last updated” date above will change with it. Material changes will also be reflected in the extension's Chrome Web Store listing.
